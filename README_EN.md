## 📖 What Is This

**GEO (Generative Engine Optimization)** is the AI-era successor to SEO: it measures a brand's **visibility, citation rate, ranking, and sentiment** inside answers generated by AI models (Doubao, DeepSeek, ChatGPT, Claude, etc.).

As more users ask AI for purchase advice, whether a brand gets mentioned and recommended in AI answers directly shapes business outcomes. **SouGEO CLI** (`npm i -g @yooai/sougeo-cli`) is the command-line client of the SouGEO GEO platform; this Skill lets AI agents drive it via natural conversation and complete the whole workflow on the user's behalf.

## 🎯 Core Problems It Solves

| Pain Point | SouGEO's Answer |
|---|---|
| **Brand performance in AI is a black box** — when users ask AI "which phone should I buy?", there's no way to know if you're mentioned or how you're rated | GEO insight reports quantify **AI visibility / brand index / citation rate / ranking / sentiment**, delivered as an online report link |
| **Unreliable testing** — test questions containing the brand name feed the answer to the AI | The Skill enforces **user-perspective GEO test questions that exclude the tested brand** (with decision-guiding words and selling-point keywords), picked by the user, keeping tests honest |
| **High barrier of traditional monitoring** — parameters, scripts, environment setup | **Zero barrier**: one sentence ("test how Xiaomi shows up in AI") triggers everything; the Agent guides parameter collection step by step with recommended defaults |
| **Fragmented platforms** — AI assistants are scattered; asking each one manually is costly | One report covers **11 platforms** (7 China + 4 overseas), generated in one run with cross-platform comparison |
| **Hard report delivery** — screenshots, exports, forwarding after generation | Reports get an **online link** automatically, plus one-click `share_code` sharing links with on-site viewer and access records |
| **Cost concerns** — hesitant to try | **Express brand reports / free industry reports require no rights check** — install and run for free |

## ✨ Features

- 🗣️ **Zero-barrier conversational creation**: auto-detects brand/industry report intent, guides parameter collection step by step (company/personal brand detection, brand-derived product/role type candidates, IP-geolocation-based location resolution) — all pickable with recommended defaults
- 🌏 **11 AI platforms covered**: 7 China platforms by default, 4 overseas platforms opt-in
- ⚡ **Complete loop**: `create → status --watch (poll to completion) → read --type link (link + brief summary) → share (re-sharing)`
- 📊 **Three report types**: brand reports (company/personal), industry reports, shield reports; paginated history queries
- 💰 **Rights & plan management**: balance query, plan list, purchase, order verification
- 🔐 **Dual login**: device-code login / token login; `auth status -o json` for structured login state
- 🖥️ **Cross-platform out of the box**: Windows / Linux / macOS (x64 / arm64), **0 npm dependencies**, native binary auto-downloaded on install

## 📦 Installation

> ### ⚠️ Installation is a two-step process: Skill first, then CLI
> The Skill itself is just an "instruction manual" for the agent — **the SouGEO CLI is what actually runs the reports**, so installing the Skill alone won't produce reports. Flow: ① install the Skill via any option below → ② **install the CLI as guided by the Skill** (SKILL.md has built-in CLI install & verification steps; the agent auto-detects and guides the installation on first run — or install it manually beforehand as shown below).

**Option 1: via the `skills` CLI (recommended)**

```bash
npx -y skills add https://github.com/YOOTeam/SouGEO-CLI
```

List installed skills:

```bash
npx -y skills list
```

**Option 2: let your AI Agent install it (zero commands)**

Just tell any Skill-capable AI agent (Trae, WorkBuddy, Claude Code, Cursor, etc.) in one sentence — the agent will fetch and install the skill into its own skills directory. Pick either repo: GitHub (global) or Gitee (faster in mainland China):

```
Install the SouGEO skill for me. The skill files live under skills/sougeo-brand-report/ (with SKILL.md) in either repo:
- GitHub: https://github.com/YOOTeam/SouGEO-CLI
- Gitee (faster in China): https://gitee.com/AiDoDesign/sougeo_cli
Download that directory from either repo into your skills directory, then check whether the
sougeo CLI is available; if not, install it via npm (npm i -g @yooai/sougeo-cli).
```

Perfect for users who never want to touch a terminal — once installed, just say "make me a GEO report".

**Option 3: manual install**

Download the [`skills/sougeo-brand-report/`](https://github.com/YOOTeam/SouGEO-CLI/tree/main/skills/sougeo-brand-report) directory (same path in the Gitee repo) and copy it into your agent's skills directory (e.g. `~/.workbuddy/skills/`, `~/.claude/skills/`).

> 📁 Repo layout: the skill itself lives under the **`skills/`** subdirectory (`skills/sougeo-brand-report/SKILL.md`), not the repo root — point manual installs and agent downloads at that path.

### After the Skill is installed: install the SouGEO CLI (required, guided by the Skill)

Once the Skill is installed it **cannot produce reports by itself** — it needs the SouGEO CLI it drives. The Skill has built-in CLI install, verification, and troubleshooting guidance: **just say "make me a GEO report" to your agent; it will auto-detect the CLI and install it via npm per the Skill's instructions if missing**. You can also install it manually beforehand:

```bash
npm i -g @yooai/sougeo-cli      # requires Node >= 16; command name: sougeo
sougeo version show             # prints a version = installed successfully
```

> 💡 Network tip: if the npm mirror reports `404 not in this registry` (mirror sync lag for new packages), install from the official registry:
> `npm i -g @yooai/sougeo-cli --registry=https://registry.npmjs.org`

## 🚀 Quick Start

Just say one sentence to your agent:

```
Analyze how Xiaomi shows up in AI answers
```

The agent runs the full loop automatically:

```
User: "Analyze Xiaomi for me"
  ↓ Check CLI availability (auto-install via npm if missing)
  ↓ Detect: brand report → ask company or personal brand
  ↓ Generate product-type candidates from the brand (smartphones / smart home / SU7…)
  ↓ Generate user-perspective GEO test questions → user picks (≤3, none contain "Xiaomi")
  ↓ Location resolution (vague words via IP geolocation) → confirmation sheet → user confirms
  ↓ sougeo report create → sougeo report status <id> --watch → sougeo report read <id> --type link
  ↓ Deliver: brief summary (brand index etc.) + 🔗 online report link
```

Or drive the CLI directly:

```bash
sougeo auth login                                        # first-time login
sougeo report create -r brand -b Xiaomi -a company -p smartphone \
  -q "Besides the big brands, what good-value phones are worth considering?" \
  -q "What phone under 3000 CNY would you recommend for students?" \
  -l 1 -P 1,3,4,5,6,7,8                                  # Express tier + 7 China platforms, free
sougeo report status <report_id> --watch                 # poll until completion
sougeo report read <report_id> --type link               # fetch the online report link
```

## 💡 Usage Tips

- Trigger the agent with "make me a GEO report / test brand X / industry analysis" — **don't assemble parameters yourself**; the Skill has a built-in guided collection flow.
- Test questions are the key to GEO: write from the user's perspective, include decision-guiding words, and **never include the tested brand name** (brand ≤3 / industry ≤6).
- Report generation is async — use `report status --watch` and fetch the link only after completion.
- Share links (`https://sougeo.com/ReportResults?share_code=<code>`) require a SouGEO login to view; viewer and access records are visible on the official site after sharing.
- If the Skill content ever conflicts with actual CLI output, the CLI output wins.
